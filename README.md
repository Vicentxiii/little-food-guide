# Little Food Guide

Landing page para o produto digital **Little Food Guide** — um guia prático de 28 páginas para começar alimentação complementar em bebês de 6 a 24 meses.

## Conteúdo

- `index.html` — estrutura da landing page (hero, problema, solução, conteúdo, depoimentos, oferta e FAQ)
- `css/style.css` — estilos e responsividade
- `images/` — imagem de capa do guia

## Como visualizar

É um site estático, sem dependências ou build. Basta abrir o `index.html` no navegador, ou servir a pasta localmente:

```bash
# Python
python -m http.server 8000

# ou, com Node.js
npx serve .
```

Depois acesse `http://localhost:8000`.

## Tecnologias

HTML5, CSS3 e Google Fonts (Fraunces e Figtree). Sem frameworks ou bibliotecas JavaScript.
